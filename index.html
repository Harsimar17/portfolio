LinkedIn Job Intelligence Suite

Repository: LinkedIn-Job-Finder

The LinkedIn Job Intelligence Suite is a scraping pipeline that turns the LinkedIn job feed into a focused shortlist of roles with fewer than 100 applicants.

Result

It filtered 100+ roles into a shortlist. Applying selectively from that list produced 5–10 interview calls, a far higher response rate than the open job feed.

How it works

  • Two modes: an authenticated session that reads job data from the JSON embedded in the page, and an unauthenticated fallback that parses the public HTML job cards.
  • Visits each job's detail page to add the applicant count, with three fallback methods so it keeps working through page redesigns.
  • Search by role, location and recency down to the last hour, paginated in steps of 25 with randomized delays between requests.
  • De-duplication, a summary table in the terminal, and CSV export that appends to an existing file.

Wifi Interceptor

Repository: Wifi-Interceptor · educational and authorized security testing only

Wifi Interceptor is an educational man-in-the-middle tool built with Scapy. It discovers devices on a local network and shows which domains they connect to, to demonstrate how much an attacker on the same network can see even when traffic is encrypted.

How it works

  • Runs an ARP scan of the subnet to discover connected devices.
  • Uses ARP spoofing to route traffic between devices and the router through the host, with IP forwarding enabled so devices keep their internet access.
  • Extracts domains from the TLS ClientHello SNI field, which works even over HTTPS, and from plaintext DNS queries on UDP port 53.
  • Restores the original ARP tables cleanly on exit.

Details

  • Output is tagged by source IP and detection method.
  • A configurable noise list hides ad, tracker and telemetry domains, and subdomains collapse to their registered domain, including multi-part TLDs.
  • The README documents the limits of each method: encrypted DNS (DoH/DoT), ECH and private relays can hide domains.

Mac Remote File Server

From Harsimar's project files

The Mac Remote File Server is a zero-install remote filesystem gateway written in Java, with a browser-based terminal UI to browse, upload, download and delete files over LAN or the internet.

Engineering

  • Multipart binary streaming for files of any size.
  • A canonical-path sandboxing layer that blocks directory-traversal attacks.
  • IP-level request logging as an audit trail.

Access & interface

  • Ngrok reverse tunnelling for access through NAT and firewalls with a single command.
  • A voice-driven terminal (Web Speech API, Tab autocomplete) in vanilla JavaScript with zero frontend dependencies.

Deutsch Vocab Trainer

From Harsimar's project files · Deutsch lernen

The Deutsch Vocab Trainer is an interactive web app I built to learn German vocabulary, with flashcards and quizzes covering the full A2 word list: nouns grouped by article, verbs, adjectives, function words and everyday phrases.

Features

  • Flashcard mode for review and a quiz mode for testing yourself.
  • Scores persist per browser through Firebase Firestore with anonymous authentication, so no sign-up is needed.
  • An all-time running score, plus per-round history to save past quiz rounds and compare them by date and score.

Deployment

  • Version 2 runs as a Docker-based service on Render, placed in a US East region to sit close to the Firestore database.
